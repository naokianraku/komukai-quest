# ストア用スクリーンショットの撮り方

6.9インチ（2868×1320）。シミュレーター iPhone 17 Pro Max で撮って `sips -r -90` で横にする。

```bash
SIM=264BF619-05C9-481D-BA48-FA014B4398F0
xcrun simctl launch "$SIM" com.anraku.komukai -game "<クエリ>"
xcrun simctl io "$SIM" screenshot --type=png raw.png
sips -r -90 raw.png --out out.png
```

`shot=秒` を付けると、その秒数ぶん進めて**画を止める**ので毎回同じ絵が撮れる。
ios/CLAUDE.md のキー一覧に無いが実装済み（game3d/src/main3d.js:360）。
**指定の約2倍進む**（1枚目と2枚目の両方で効くため）。`shot=1.6` ≒ 3.2 秒。

| 枚 | クエリ | 何を見せるか |
|---|---|---|
| 1 | （なし） | タイトル・作業指示書・難易度 |
| 2 | — | 道中の戦闘 |
| 3 | `stage=3&demo=1200&shot=1.6` | 中ボス 生産企画課長 |
| 4 | — | ボス 工場長（稲荷社） |
| 5 | `stage=ura&demo=340&shot=2.5` | 業火の60号7階Aゾーン（敵なし） |
| 6 | — | 本社 事業部フロア |

## 踏んではいけない値

- **`stage=3` は自機を x=1140 付近に置かないこと。** フリップチャートが
  ゲーム座標 300 / 720 / 1140 / 1560 に立っていて、真後ろに入ると中ボスが完全に隠れる。
  1.0 の 3_midboss.png がこれだった。1200 か 1240 が安全
- **業火は `shot` を 10 秒ぶん以上にしないこと。** 5人衆の出現から 20 秒で魔王Y下が
  降りてきて、体力バーに名前が出る。隠しボスなのでストアには出さない
  （5人衆の名札は N村 / K目 / S田 / H本 / H野 で、魔王の名前は含まない）
- バナーは場面で 2.8 秒・波で 2.6 秒。消したいならそれ以降まで進める
- 吹き出しの実名は **1.0.1 でソフト側を直した**（2026-11-07）。
  名札は伏せ字なのにセリフだけ実名が出ていたので、ゲーム本体を
  N村・K目 に揃えた。以降は吹き出しが写っても構わない
- **業火で5人衆を映すと必ず誰かが喋る。** 5体が常時しゃべるため、
  `shot` を 2.8〜8.0 秒のどこで止めても吹き出しが出た（実測12点すべて）。
  敵を出さずに撮ること。波の境目は `player.x > 480-130 = 350` なので `demo` は 349 以下
